Jogos

Aberto: qualquer pessoa com o link joga (com a senha dos jogadores, se estiver ligada). Fechado: aparece a tela "Fechado no momento". Você (ADM) sempre entra em tudo, inclusive nos ADMs dos jogos.

Senha dos jogadores

Ligada: quem abre um jogo aberto digita a senha uma vez (o navegador lembra). Trocar a senha faz todo mundo digitar a nova. O ADM não precisa de senha.

Cadastrar um jogo novo

Jogos novos do GitHub já aparecem na lista em "Sem cadastro". Se não aparecer, digite o nome do repositório.
